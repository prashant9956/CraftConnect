# 🎨 CraftConnect

### AI-Powered Artisan Marketplace

CraftConnect is a full-stack web platform that helps **local artisans
showcase their handmade products and connect with buyers online**.

The platform also uses **AI to help artisans create product listings
from product images**, making the listing process faster and easier.

---

## 💡 What is CraftConnect?

Many local artisans create unique handmade products but may find it
difficult to present and sell their products digitally.

CraftConnect provides a simple platform where:

👨‍🎨 **Artisans** can upload and manage their products.

🤖 **AI** can analyze a product image and suggest product details.

🛍️ **Buyers** can discover and search for handmade products.

🛒 **Buyers** can add products to their cart.

👨‍💼 **Admins** can monitor users and products.

---

## ✨ Main Features

### 🤖 AI Product Listing

Upload a product image and AI can suggest:

- Product Name
- Category
- Material
- Description
- Tags

The artisan can **review and edit the AI-generated information**
before publishing the product.

### 👨‍🎨 Artisan Dashboard

Artisans can:

- Add products
- Use AI-assisted product creation
- View their products
- Edit products
- Delete products
- Manage their product listings

### 🛍️ Marketplace

Buyers can:

- Browse handmade products
- Search for products
- Filter products by category
- View product details
- Add products to cart

### 🛒 Shopping Cart

Buyers can:

- Add products
- Increase quantity
- Remove products
- View the total cart value

### 🔐 Authentication

The application supports secure login and signup with different
user roles:

- Buyer
- Artisan
- Admin

Each role gets access to its relevant features.

### 👨‍💼 Admin Dashboard

The admin can:

- View platform statistics
- Manage users
- Manage products
- Monitor artisans and buyers
